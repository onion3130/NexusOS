# NexusOS v1.0.1

NexusOS v1.0.1 is a packaging patch for the v1.0.0 Raspberry Pi release.

## Fix

- Fixed the ARM64 web image Dockerfile to copy `apps/web/package-lock.json` before running `npm ci`.
- This restores reproducible web image builds from a fresh clone and prevents Docker builds from failing with a missing lockfile error.

## Validation

- Backend tests: 46 passed
- Frontend TypeScript typecheck: passed
- Frontend production build: passed
- Dockerfile reviewed for ARM64 compatibility and lockfile-based installation

Docker image build and runtime verification still require Docker on the target Raspberry Pi or another ARM64 host.

## Installation

Use the `v1.0.1` tag and follow [`docs/DEPLOYMENT.md`](../DEPLOYMENT.md). Keep the initial owner bootstrap interactive; never place the owner password in a file, command line, or chat.

No v2.0 development is included in this patch release.
