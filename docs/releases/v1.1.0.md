# NexusOS v1.1.0

NexusOS v1.1.0 completes Milestone 11 (part 2): calendar, finance, media, and the security-first out-of-process plugin boundary.

## Highlights

- **Calendar** — user-owned events, categories, all-day support, date-range filtering, reminders, and worker-delivered notifications.
- **Finance** — integer-cent accounts and transactions, categories, period summaries, and strict all-or-nothing CSV import.
- **Media** — approved-root indexing, sensitive-file exclusion, deterministic hashes, bounded Pillow thumbnails, background rescans, and confined private streaming.
- **Plugins** — operator-approved manifests, capability risk labels, JSON-stdio subprocess execution, Linux resource limits, bounded timeout/output, audited lifecycle actions, and bounded run history.
- **Assistant integration** — `plugins.invoke` is always confirmation-gated; direct HTTP invocation is limited to read-risk capabilities.
- **Dashboard** — new Calendar, Finance, Media, and Plugins workspaces with loading, error, empty, and responsive states.
- **Deployment** — ARM64 Docker Compose mounts the plugin directory read-only into API and worker services.

## Security

- Plugin subprocesses receive a minimal environment and never inherit JWT, AI, SMTP, or backup-encryption secrets.
- Plugin entrypoints are confined beneath the operator-approved plugin directory and launched without a shell.
- Lifecycle changes require explicit confirmation and are audited.
- Write and dangerous capabilities cannot be invoked through the direct HTTP route.
- Plugins are trusted operator-installed code, not a complete hostile-code sandbox. Use a separate VM or container boundary for untrusted extensions.

## Upgrade notes

1. Back up the database before upgrading.
2. Pull the `v1.1.0` tag.
3. Set `PLUGINS_DIR` only if using operator-approved plugins; leave it empty to disable discovery.
4. Apply migrations explicitly with `python -m alembic upgrade head` or the documented Compose command.
5. Restart API and worker processes after migration.
6. Review the [plugin boundary guide](../PLUGIN_BOUNDARY.md) before installing any plugin.

NexusOS remains intended for private, local-first Raspberry Pi use. Do not expose the default Compose topology directly to the public internet.
