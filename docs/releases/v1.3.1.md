# NexusOS v1.3.1

NexusOS v1.3.1 is a compatibility patch for upgrading existing deployments to the current database schema.

## Fixes

- Fixed permission-seeder queries in migrations `0012_calendar`, `0013_finance`, `0014_media`, `0015_plugins`, and `0016_embeddings`.
- The migrations now correctly treat `role_permissions` as a composite `(role_id, permission_id)` table instead of selecting a nonexistent `id` column.
- Added regression coverage for upgrading a legacy `0006_v1_hardening` database through the current `0016_embeddings` head.
- Preserved all v1.3.0 NVIDIA NIM configuration, credential fallback, hosted endpoint defaults, and security boundaries.

## Validation

- Legacy migration upgrade: passed.
- Full backend suite: passed — 139 tests.
- Python compilation: passed.
- Frontend TypeScript typecheck: passed.
- Frontend production build: passed.
- Docker/Pi deployment: this patch is required before readiness can reach `0016_embeddings` on an existing v1.0/v1.1 database; deployment validation follows publication.

## Upgrade

```sh
git fetch --tags origin
git checkout v1.3.1
# Preserve the existing .env and data volume.
docker compose --env-file .env stop nexus-api nexus-worker
docker compose --env-file .env run --rm nexus-api python -m alembic upgrade head
docker compose --env-file .env up -d --force-recreate nexus-api nexus-web nexus-worker nexus-proxy
```

Do not delete the data volume. The migration is intended to upgrade the existing database in place.
