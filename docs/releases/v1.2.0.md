# NexusOS v1.2.0

NexusOS v1.2.0 adds optional semantic and hybrid retrieval for private notes while preserving lexical search and the local-first Raspberry Pi architecture.

## Highlights

- Optional provider-neutral embeddings for deterministic note chunks.
- Bounded serialized-vector storage and cosine similarity without a mandatory native SQLite extension.
- Dedicated worker processing with leases, bounded batches, retries, and stale-content detection.
- Lexical, semantic, and hybrid retrieval modes with source-aware provenance.
- Embedding status endpoint with no vector or credential disclosure.
- Assistant note search supports retrieval-mode metadata while remaining read-only.
- Semantic retrieval is disabled by default and falls back to lexical search when unavailable.

## Security and privacy

- Embeddings are user-scoped derived data.
- Provider credentials and raw upstream payloads are never persisted or returned.
- External providers receive note text only when explicitly enabled by the operator.
- Deleted notes and cross-user chunks are excluded from semantic ranking.
- Retrieved content remains untrusted source material and cannot grant tool permissions.

## Configuration

Set the following server-side variables to enable embeddings:

```dotenv
EMBEDDING_PROVIDER=openai_compatible
EMBEDDING_BASE_URL=https://your-provider.example/v1/embeddings
EMBEDDING_API_KEY=replace-with-a-secret
EMBEDDING_MODEL=your-embedding-model
```

Leave `EMBEDDING_PROVIDER=disabled` to use lexical search only.

Back up the SQLite database before upgrading, run `alembic upgrade head`, and leave embeddings disabled until the provider endpoint, privacy policy, and ARM64 worker behavior have been reviewed.
