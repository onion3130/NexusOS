# NexusOS v1.0.0

NexusOS v1.0.0 is the first private, local-first release of a personal AI operating system designed for Raspberry Pi 5.

It combines an authenticated dashboard, productivity tools, bounded assistant capabilities, read-only system telemetry, scoped search, and confirmation-gated maintenance workflows while keeping arbitrary host control out of the product boundary.

## Highlights

- Authenticated local dashboard with responsive Next.js UI
- Server-side, provider-neutral AI assistant gateway
- Optional OpenAI-compatible and NVIDIA NIM provider support
- AI-disabled mode for safe operation without a provider
- Task management with due dates, priorities, categories, tags, recurrence, and reminders
- Persistent in-app notifications with a dedicated SQLite worker
- Private notes with tags, archive/restore, content versions, and soft deletion
- SQLite FTS5 lexical search with source-aware retrieval chunks
- Read-only Raspberry Pi CPU, memory, storage, temperature, uptime, and network telemetry
- Confirmation-gated assistant task actions
- Confirmation-gated maintenance proposals for database backups and integrity checks
- Audit history for maintenance workflows
- ARM64-compatible, non-root Docker Compose topology

## Security and reliability

- Argon2id password hashing
- Session refresh rotation and revocation
- HttpOnly authentication cookies with CSRF protection
- Server-side permissions and resource ownership checks
- Payload validation and mutation idempotency
- Bounded assistant context, output, provider timeouts, and tool inputs
- Explicit confirmation required for assistant mutations and host actions
- No arbitrary shell commands, Docker socket, reboot, shutdown, package manager, systemd, restore, or dynamic filesystem operations
- Durable worker leases with stale-job recovery and three-attempt retry limits
- Deterministic, retry-idempotent SQLite backups
- Backup path containment, SHA-256 metadata, SQLite integrity checks, and tamper detection

## Database and operations

- Alembic migrations through `0006_v1_hardening`
- SQLite WAL mode, foreign keys, busy timeout, and worker claim indexes
- Dedicated API and worker processes
- External SSD support through `DATA_DIR`
- Loopback-only published ports in the development Compose topology
- Private Compose network and non-root runtime containers

## Known limitations

NexusOS v1.0.0 is intended for private, local-first Raspberry Pi use. It should not be exposed directly to the public internet.

The following remain outside this release or require external deployment validation:

- Docker image builds and Compose runtime validation
- Raspberry Pi 5 ARM64 runtime and sustained-load validation
- Reverse-proxy TLS and public ingress
- Encrypted off-host backup replication
- Restore drills and backup-before-migration automation
- Retention cleanup and systemd orchestration
- Production monitoring and rollback automation
- Embeddings, semantic search, autonomous memory, and RAG execution
- Email, SMS, push, and calendar notification channels

## Upgrade and deployment notes

1. Back up the existing SQLite database before upgrading.
2. Copy `.env.example` to `.env` and configure a strong `JWT_SECRET`.
3. Validate the environment with `python scripts/validate_env.py --env-file .env`.
4. From `apps/api`, apply migrations explicitly with `python -m alembic upgrade head`, or use the documented Compose command from the repository root.
5. Bootstrap the first owner account explicitly.
6. Validate `/api/v1/health/live` and `/api/v1/health/ready`.
7. On Raspberry Pi, keep `DATA_DIR` on the external SSD and complete the Docker/ARM64 validation gate in [`docs/DEPLOYMENT.md`](../DEPLOYMENT.md).

## Manual GitHub release steps

GitHub CLI is unavailable in the release environment. To publish the release manually on GitHub:

1. Open the repository's **Releases** page.
2. Select **Draft a new release**.
3. Choose the pushed tag `v1.0.0`.
4. Use this document as the release description.
5. Set the release title to `NexusOS v1.0.0`.
6. Publish the release.

No v2.0 development is included in this release.
